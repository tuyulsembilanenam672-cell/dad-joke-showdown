A single original dad joke, written by a small program to `/output/entry.txt`, for make.fun's "Dad Joke Showdown" bounty.

## Run it

```sh
node main.ts
```

It validates the joke (one line, 1–200 characters, valid UTF-8, not whitespace-only) and writes it to `/output/entry.txt`.
